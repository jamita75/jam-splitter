# JAM SPLITTER — free stem separation for Windows

![JAM SPLITTER](https://www.creaitivity.it/wp-content/uploads/2026/10/jam-splitter-separare-voce-e-strumenti.jpg)

**Split any song into separate tracks:** vocals, drums, bass, guitar, piano. Everything runs on your computer — no file is ever uploaded.

*🇮🇹 [Versione italiana più sotto](#italiano)*

## ⬇ Download and install
1. Install **[Python](https://www.python.org/downloads/)** and tick *Add Python to PATH*
2. **[Download JamSplitter.zip](https://github.com/jamita75/jam-splitter/releases/latest)** and unzip it into a folder, e.g. `C:\JamSplitter`
3. Double-click **INSTALLA_JAM_SPLITTER.bat** (one-time setup: about 2.5 GB, 10–25 minutes)
4. From then on, launch it with **AVVIA_JAM_SPLITTER.bat**

To uninstall, just delete the folder: nothing is written anywhere else. The interface is available in Italian and English.

## What it does
| Mode | Stems | Notes |
|---|---|---|
| **Standard** | vocals · drums · bass · other | best balance, ~320 MB model on first use |
| **Refined** | vocals · drums · bass · other | higher quality, about 4× slower, ~1 GB |
| **Extended** | + guitar · piano | 6 stems, ~350 MB |

- **Vocals + backing only**: two tracks, the fastest option for karaoke and a cappellas
- Batch queue for multiple songs, full-quality **WAV** export
- Typical times (4-minute song, no dedicated GPU): Standard 2–5 min · Refined 8–20 min · Extended 3–6 min
- Tip: always start from the best source you have (WAV or 320 kbps MP3)

## Italiano
**Da una canzone a tracce separate:** voce, batteria, basso, chitarra, piano. Tutto sul tuo computer, nessun file caricato su internet.

1. Installa [Python](https://www.python.org/downloads/) spuntando *Add Python to PATH*
2. [Scarica JamSplitter.zip](https://github.com/jamita75/jam-splitter/releases/latest) ed estrailo in una cartella, per esempio `C:\JamSplitter`
